# Расписание занятий — приложение (PWA)

Мини-приложение с расписанием на неделю и переключением «Неделя 1 / Неделя 2».
Работает в браузере телефона, ставится на домашний экран как обычное приложение.

## Как открыть

В папке с приложением выполнить:

```powershell
node serve.mjs
```

Скрипт напишет два адреса:

- `http://localhost:8099` — на компьютере;
- `http://192.168.x.x:8099` — на телефоне (телефон должен быть в той же Wi-Fi).

Порт можно поменять: `node serve.mjs 8080`.

> Просто открыть `index.html` двойным щелчком тоже можно, но тогда не заработает
> офлайн-режим (service worker требует http, а не file://).

## Как поставить на телефон

**Android (Chrome):** открыть адрес → меню «⋮» → «Добавить на главный экран» /
«Установить приложение».

**iPhone (Safari):** открыть адрес → «Поделиться» → «На экран „Домой“».

Иконка появится на домашнем экране, приложение откроется без адресной строки.

## Как менять расписание

Всё расписание лежит в одном файле — `schedule.js`. Открыть любым редактором,
поправить, сохранить, обновить страницу.

```js
{
  start: "08:00",       // начало пары
  end: "09:30",         // конец пары
  kind: "пр.",          // пр. / л. / лаб. — значок перед названием
  subject: "Технология разработки ПО",
  room: "119",          // кабинет
  teacher: "Чербенко К. Н."   // необязательно
}
```

День без пар — просто `[]` или день не указывать вовсе.

**Недель может быть больше двух.** Добавьте третий объект в массив `weeks` —
приложение начнёт переключать их по кругу в указанном порядке.

**Какая неделя идёт сейчас** — считается от даты `meta.semesterStart`
(понедельник недели №1). Если приложение ошиблось, внизу есть ссылка
«не та неделя?» — она сдвигает нумерацию и запоминает выбор на этом устройстве.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `schedule.js` | **данные расписания** — правим только его |
| `app.js` | логика: даты, недели, подсветка текущей пары, тема |
| `styles.css` | оформление, тёмная и светлая тема |
| `index.html` | каркас страницы |
| `manifest.webmanifest` | имя, иконки, режим «как приложение» |
| `sw.js` | офлайн-кэш |
| `icons/` | иконки приложения |
| `serve.mjs` | локальный сервер без зависимостей |

## Публикация в интернете (необязательно)

Чтобы открывать расписание не только по домашней Wi-Fi, папку можно залить
на любой бесплатный статический хостинг: GitHub Pages, Netlify, Cloudflare Pages.
Просто перетащить папку, сборка не нужна. На HTTPS офлайн-режим заработает
и на телефоне.
